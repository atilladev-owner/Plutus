# Plutus

A multi asset ledger and paper trading exchange API. Double entry accounts, row locked transfers, holds, idempotency keys, signed webhooks, and a hash chained journal anyone can verify live.

Express 5, TypeScript, Postgres. Built in two milestones: the ledger first, the exchange on top of it.

## Status

Designing. The approved design lives at `docs/superpowers/specs/2026-09-04-plutus-design.md`. Nothing is deployed yet.
