The stream

Waiting for JavaScript

GET /v1/exchange/stream is Server Sent Events, not a WebSocket: a plain HTTP response a browser reads with EventSource. This panel opens one for the market above and counts every message it receives.

Events received

0

const stream = new EventSource(
  "/v1/exchange/stream?channels=book:BTC-USDT,trades:BTC-USDT&since=0"
);
stream.onmessage = (event) => {
  const { channel, seq, data } = JSON.parse(event.data);
};
