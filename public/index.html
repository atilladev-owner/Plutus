plutus

A ledger you can audit and an exchange you can trade against.

Plutus is a ledger, and from milestone two a paper trading exchange, built as a single API. Mint a key with no signup, open a ledger, and move money between accounts under invariants the database enforces itself.

Every amount is an integer count of the asset's smallest unit, never a float. Each write, a transfer, a hold, a capture, runs as one Postgres function under row locks, so two requests racing for the same balance cannot both win.

Every write also appends to a hash chained journal. Each entry commits the hash of the one before it, so one request can prove the whole history is intact, not only the balances it left behind.

Thirty seconds

# 1. a key, no signup
curl -s -X POST https://PLUTUS_HOST/v1/keys
# 2. a ledger and two accounts
curl -s -X POST https://PLUTUS_HOST/v1/ledgers -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" -d '{"name":"shop"}'
curl -s -X POST https://PLUTUS_HOST/v1/ledgers/$LEDGER/accounts -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" -d '{"asset":"GHS","name":"till"}'
# 3. money in from the world, then between accounts
curl -s -X POST https://PLUTUS_HOST/v1/ledgers/$LEDGER/transfers -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" -H "Idempotency-Key: fund-1" -d '{"legs":[{"from":"world:GHS","to":"'$TILL'","asset":"GHS","amount":"125000"}]}'
# 4. prove the books
curl -s https://PLUTUS_HOST/v1/ledgers/$LEDGER/verify -H "Authorization: Bearer $KEY"
